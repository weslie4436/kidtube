# KidTube

小孩打開的目錄，長得像 YouTube。裡面只有放行的頻道。點一部影片會留在這個網站裡播，右邊只列出白名單裡的下一部，不會進 YouTube 那個帶推薦的觀看頁。嵌入的播放器不一定吃得到 Premium，所以廣告有時還會出現。

網址：https://weslie4436.github.io/kidtube/

## 家長要做的

1. 要整個放行的頻道，把頻道網址貼進 `channels.json` 的 `channels`，一個頻道一次。新片會自己進來。
2. 只准幾支、不准整個頻道時，才另外用一個**不公開**播放清單，把 `list=` 後面那一串填進 `playlist.json`。私人清單讀不到。
3. iPad 的 YouTube App 和 Safari 都登入有訂閱的帳號。
4. 小孩只收藏上面那個網址。真正的 YouTube 圖示不要留在主畫面。

知道這個網址的人看得到同一份標題和縮圖。網頁沒有你的密碼，也請搜尋引擎不要收錄。
