# KidTube

小孩打開的目錄，長得像 YouTube。裡面只有放行的播放清單。點一部影片，會打開這台裝置上已經登入的 YouTube，所以 Premium 的免廣告才用得上。

網址：https://weslie4436.github.io/kidtube/

## 家長要做的

1. 用有訂閱的帳號，在 YouTube 建一個**不公開**播放清單，把可以看的片加進去。私人清單這裡讀不到。
2. 把清單網址裡 `list=` 後面那一串填進 `playlist.json` 的 `playlistId`。
3. iPad 的 YouTube App 和 Safari 都登入同一個帳號。
4. 小孩只收藏上面那個網址。真正的 YouTube 圖示不要留在主畫面。

知道這個網址的人看得到同一份標題和縮圖。網頁沒有你的密碼，也請搜尋引擎不要收錄。
